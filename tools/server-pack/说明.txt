DIE_Reborn 服务器包 (Windows Server, 阿里云 ECS)
==============================================

本包自带 .NET 运行时和游戏数据, 服务器上不用装 .NET、不用装游戏、不用装 Steam。

服务器公网地址: {PUBLIC_HOST}   (写在 DIE_Server\public-host.txt)

一、阿里云安全组 (只做一次, 在阿里云网页控制台里)
----------------------------------------------
实例详情 -> 安全组 -> 配置规则 -> 入方向 -> 手动添加, 加四条:

  协议   端口范围          授权对象
  TCP    1555/1555         0.0.0.0/0     (大厅: 登录 / 菜单 / 商店)
  TCP    2555/2555         0.0.0.0/0     (匹配 / 开局)
  TCP    8555/8555         0.0.0.0/0     (登陆器: 在线人数 / 补丁镜像, 只读)
  UDP    50000/50099       0.0.0.0/0     (战斗服, 每局占一个)

远程桌面用的 TCP 3389 应该已经有了, 别删。

二、放到服务器上 (只做一次)
------------------------
1. 远程桌面连上服务器, 把整个 DIE_Server 文件夹复制过去, 比如 C:\DIE_Server。
   (路径里最好别有中文)
2. 右键 DIE_Server 里的「开放防火墙.cmd」-> 以管理员身份运行。

三、开服
------
双击「启动服务器.cmd」。窗口里依次出现这几行就是正常的:

  游戏数据已加载: C:\DIE_Server\gamedata
  Request 服务器已监听 0.0.0.0:1555
  匹配服务器已监听 0.0.0.0:2555
  服务器公网地址 {PUBLIC_HOST} -> {PUBLIC_HOST}
  已以匿名游戏服务器登录 Steam ...        (启动后几秒)

- 关掉窗口就是关服。远程桌面直接点右上角 X 断开没关系, 服务器照跑;
  但别在服务器上"注销", 那会把它一起关掉。
- 玩家登录时窗口里会出现 "Steam 核验通过 SteamID ..."。

四、客户端
--------
玩家的 ip.cfg 要指向 {PUBLIC_HOST}:
- 朋友: 用最新的「DIE_朋友客户端包」, 里面已经填好了。
- 你自己: 双击游戏目录里的「设置服务器地址.cmd」, 输入 {PUBLIC_HOST}。
  (想回到本机开发服, 再运行一次输入 127.0.0.1)

五、数据和日志
------------
DIE_Server\data\die_reborn.db     所有账号 (进度、背包、货币)。备份它 = 备份全部账号。
DIE_Server\logs\                  服务器日志, 按天一个文件。出问题把当天的发给我。

六、以后更新服务器
----------------
1. 关服 (关掉窗口)。
2. 用新包里的 DIE_Server 覆盖服务器上的文件夹。
   新包里没有 die_reborn.db, 覆盖不会动到账号 —— 但保险起见, 覆盖前先备份 data\die_reborn.db。
3. 重新开服。

六点五、把本机账号进度搬到服务器上
------------------------------
(只有用仓库根「打包服务器(带本机账号).cmd」打的包 (即 -ImportLocalAccounts), DIE_Server\import\ 里才有 die_reborn.db;
 普通的「打包服务器.cmd」不带)
1. 关服。
2. 双击「导入本机账号.cmd」: 先预演列出要导入的账号 -> 输入 Y 确认 -> 自动备份 data\die_reborn.db 后导入。
   按 Steam ID 对人: 服务器上已有的这个人, 进度换成本机的; 没有的新建; 其他玩家不动。
3. 开服。

七、注意
------
- 公网 IP: 现在的 {PUBLIC_HOST} 是实例自带的公网 IP。按量付费实例如果"节省停机",
  公网 IP 可能被回收, 再开机就变了。建议在实例页面点「转换为弹性公网 IP」固定下来;
  真变了就改 public-host.txt 并让大家改 ip.cfg。
- 流量: 带宽按使用流量计费, 这游戏一局的流量很小, 几个人玩费用很低。
- 服务器要能连上 Steam (核验玩家身份用)。开服几秒后没出现"已以匿名游戏服务器登录 Steam",
  把日志发给我。
